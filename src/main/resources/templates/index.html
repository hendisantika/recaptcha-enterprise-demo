reCAPTCHA Enterprise, end to end

The classic reCAPTCHA v2/v3 flow posted a token and a shared secret to siteverify and got back {"success": true}. The Google Cloud version creates an assessment instead: the browser mints a token for a named action, the server exchanges it for a risk score and reason codes, and the application decides what to do with that score.

  1. Browser

    The page loads enterprise.js?render=SITE_KEY. On submit, grecaptcha.enterprise.execute(SITE_KEY, {action: 'LOGIN'}) returns a token that is valid once, for two minutes.

  2. Your server

    POSTs the token to /v1/projects/project/assessments with an API key. The site key is public; the API key never leaves the server.

  3. Decision

    Check tokenProperties.valid, confirm tokenProperties.action is the action you expected, then compare riskAnalysis.score to your own threshold (0.5 here).
